Mon Chat Saussinois : règles de confidentialité

Mon Chat Saussinois est un jeu où l'on élève un chat. Une partie de ses bénéfices est reversée à l'association 3 Petits Chats Saussinois. Cette page explique quelles données le jeu utilise et comment garder la main dessus.

Dernière mise à jour : 16 novembre 2026.

Qui publie le jeu

Le jeu est édité par RAM RIM Stratégie (Théo Fabiani Ricaud, entrepreneur individuel, micro-entreprise), SIREN 941 068 777. Contact pour toute question sur vos données : ramrim.strategie@gmail.com.

Ce que le jeu garde, et où

Votre partie (nom du chat, niveau, pièces, tenues, scores, nombre de vidéos regardées dans la journée) est enregistrée uniquement sur votre téléphone. Elle n'est envoyée ni à nous ni à l'association. Il n'y a pas de compte à créer, pas de formulaire, et nous ne demandons ni votre nom, ni votre e-mail, ni votre position. Désinstaller le jeu efface cette sauvegarde.

Les publicités (Google AdMob)

Le jeu propose des vidéos publicitaires facultatives : vous choisissez d'en regarder une pour gagner de l'énergie ou des pièces. Ces publicités sont fournies par Google AdMob (Google Ireland Limited). Pour les afficher, Google peut recueillir et utiliser :

  • l'identifiant publicitaire de votre appareil ;
  • votre adresse IP et une position approximative (pays, région) qui en découle ;
  • des informations techniques sur l'appareil (modèle, système, langue) ;
  • vos interactions avec les publicités (vue, clic).

Ces données servent à afficher les publicités, à les mesurer, à lutter contre la fraude et, si vous l'acceptez, à les personnaliser. Elles sont traitées par Google selon ses propres règles : comment Google utilise les données des applications partenaires et règles de confidentialité de Google.

Vos choix

  • Consentement : au premier lancement, dans l'Union européenne, Google vous demande si vous acceptez les publicités personnalisées. Si vous refusez, le jeu affiche seulement des publicités non personnalisées.
  • Changer d'avis : à tout moment, dans le jeu, page Asso, bouton « Gérer mes choix pour les pubs ».
  • Identifiant publicitaire : vous pouvez le réinitialiser ou le supprimer dans les paramètres Android (Google, puis Annonces).
  • Aucune publicité obligatoire : les vidéos ne se lancent que si vous appuyez sur le bouton ; vous pouvez jouer sans jamais en regarder.

Ce que le jeu ne fait pas

Pas d'achat en argent réel : les pièces se gagnent en jouant. Pas de vente de données. Pas d'accès à vos photos, contacts, micro, caméra ou position précise : la seule autorisation demandée est l'accès à Internet, pour les publicités.

Enfants

Le jeu s'adresse aux personnes de 13 ans et plus. Nous ne recueillons sciemment aucune donnée d'enfant de moins de 13 ans.

Vos droits

Selon le RGPD, vous pouvez demander l'accès à vos données, leur rectification ou leur suppression, ou vous opposer à leur utilisation, en écrivant à ramrim.strategie@gmail.com. Les données de publicité étant traitées par Google, vous pouvez aussi utiliser Mon Centre Publicités de Google. Vous pouvez saisir la CNIL (cnil.fr).

Modifications

Si le jeu change sa façon d'utiliser les données, cette page sera mise à jour avant la nouvelle version, avec la date ci-dessus.
